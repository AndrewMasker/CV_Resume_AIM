\textbf{LMM Metal 3D Printer} \hfill 2026 -- Present

\textbf{Personal Project}\\
\begin{itemize}[noitemsep, topsep=0pt, partopsep=0pt, parsep=0pt]
    \item Designing and building a low-cost Lithography-based Metal Manufacturing (LMM) printer: a top-down DLP machine that cures a heated slurry of metal powder in a wax and photopolymer binder layer by layer.

    \item Designed the three-axis machine (reservoir piston, build platform, and heated recoater) in Onshape, and a KiCad carrier PCB for a Teensy 4.0, Raspberry Pi Zero W, stepper drivers, heater outputs, and sensors; assembled and debugged the board.

    \item Wrote C++ Teensy firmware for motion, homing, PID heater control with hard safety cutoffs, and a bit-banged SMBus driver for an IR thermometer, plus a Python print stack on the Pi with a command line and an on-machine GUI.

    \item Developed seven copper slurry formulations and three heating designs, arriving at mains cartridge heaters controlled by IR measurement of the slurry; converted a tabletop kiln with a ramp/soak controller for debinding and sintering.
\end{itemize}

\textbf{Bashputer} \hfill 2026 -- Present

\textbf{Personal Project}\\
\begin{itemize}[noitemsep, topsep=0pt, partopsep=0pt, parsep=0pt]
    \item Built a 64-bit, register-based RISC virtual machine entirely in Bash, with each hardware component (CPU, bus, memory, screen, keyboard, timer, and cartridge loader) running as its own process, a 66-instruction ISA, and memory-mapped I/O.

    \item Wrote Bassm, an assembly language and three-stage assembler (also in Bash) with scoped labels, compile-time arithmetic, and macros for structured control flow, and used it to write programs including Snake.

    \item Made the machine playable in the browser through a fork of WebVM, working around missing system calls in its x86 emulator.
\end{itemize}
