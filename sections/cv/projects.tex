\textbf{LMM Metal 3D Printer}, Personal Project \hfill 2026 -- Present
\begin{itemize}[noitemsep, topsep=0pt, partopsep=0pt, parsep=0pt]
    \item Designing and building a low-cost Lithography-based Metal Manufacturing (LMM) printer: a top-down DLP machine that cures a heated slurry of metal powder in a wax and photopolymer binder layer by layer.

    \item Designed the three-axis machine (reservoir piston, build platform, and heated recoater) in Onshape, and a KiCad carrier PCB for a Teensy 4.0, Raspberry Pi Zero W, stepper drivers, heater outputs, and sensors; assembled and brought up the board.

    \item Wrote C++ firmware for motion, homing, PID heater control with hard safety cutoffs, and a bit-banged SMBus driver for an IR thermometer, plus a Python print stack on the Pi with a command line and an on-machine GUI.

    \item Closed the loop on slurry temperature with IR sensing, iterating through three heating designs and seven copper slurry formulations.
\end{itemize}
