\textbf{LMM Metal 3D Printer}, Personal Project \hfill 2026 -- Present
\begin{itemize}[noitemsep, topsep=0pt, partopsep=0pt, parsep=0pt]
    \item New printer architecture: a top-down DLP machine curing a heated slurry of metal powder in a wax and photopolymer binder, plus a kiln converted to a ramp/soak controller for debinding and sintering.

    \item Designed the three-axis machine (reservoir piston, build platform, heated recoater) in Onshape and a KiCad carrier PCB (Teensy, Raspberry Pi, steppers, heaters, sensors); built and brought up the board.

    \item Iterated through three slurry heating designs, ending at mains cartridge heaters in machined aluminum mounts with closed-loop IR measurement of the slurry; tested seven copper slurry formulations.

    \item Wrote C++ firmware (motion, homing, PID heating, safety cutoffs) and a Python print stack with a GUI.
\end{itemize}
